## 2. What was verified, honestly

- **Real compile**: `./gradlew build` on `claude/integration` passes with zero errors (two pre-existing deprecation
  warnings). The cloud environment's network policy was opened for `maven.neoforged.net`, `libraries.minecraft.net`,
  `piston-meta/piston-data.mojang.com` and `maven.parchmentmc.org`; keep that so cloud sessions can build.
- **Quest validation**: `py make_quests.py` ran with all 100 mod jars present: no unknown IDs.
- **Live test server** (NeoForge 21.1.262, the full pack's 101 server jars, no API keys, no players): booted clean,
  Survivors 0.20.0 loaded, KubeJS grace script loaded with 0 errors. Then, with the test colony and two hired crew:
  - Phrasebook: "chop wood", "get 32 wood" handled locally; "why did you stop" correctly sent toward the model;
    "everyone, get stone" dispatched to both crew with no model call. Moss gathered 16 wood and crafted a stone pickaxe.
  - Daily rhythm: at day, "walking to the supply chest" then "gather 16 logs (nothing requested; the chests have 40
    logs, 64 cobblestone)"; at dusk, "Testville's watch tonight -> Otto (rotation)" and "back to the chest for the
    night"; at night, "night watch at the chest (9 min until dawn)".
  - Buddy rule: a far `go_to` at night with nobody free -> "won't go out alone at night", task failed with that reason.
  - Panic: zombie hits produced "Moss panics (SCREAM)" and "Otto panics (DROP_AND_RUN)".
- **Found and fixed on the test server**: with no `anthropic_key.txt` the foreman's crew-report follow-up built an HTTP
  request with a null header and **crashed the whole server** (also true of the old code; the live server has a key so it
  never showed). HaikuClient now returns null without a key and the follow-up is wrapped like the other tick work. Also:
  a leftover "back to the chest for the night" routine task survived into the next day and blocked the dawn job; the
  rhythm now drops it at daybreak.
- **Not exercised at all** (needs real players, a key, or a client): chat-vs-action-bar routing and the radio limit (D),
  trust rises/falls and the leaving path (I), the player-hurt sense (G), prompt caching and the `/foreman usage` line (C),
  colony-watch notices (C), the quest links and `min_required_dependencies` as FTB Quests renders them (A/B), buddy
  *pairing* with plot armor and the slowed state (H; the bench cap is 2 crew and one was on watch), voice lines.

## 3. Ship it (operator's PC, ~20 minutes)

1. Dev repo: `git fetch && git merge origin/claude/integration` into `main` (fast-forward), push. The jar is already in
   `build/extra_jars`.
2. Public repo: merge `claude/epic-goodall-21fmx2` into `main` and push (or `git push origin claude/epic-goodall-21fmx2:main`).
   About 60 of the changed files differ only in line endings because the pack was regenerated on Linux; packwiz will
   re-download them once on each client. If you would rather avoid that, regenerate on the PC instead:
   `py make_quests.py && py make_mrpack.py 0.4.34-alpha && py make_packwiz.py 0.4.34-alpha` then commit and push.
3. DatHost, while nobody is on: upload `mods/survivors-0.20.0.jar` and delete `survivors-0.19.0.jar`; upload
   `config/survivors/claude_context.md`, `kubejs/server_scripts/horror_grace.js`, and `config/ftbquests/quests/`
   (all from the public repo). Restart.
4. In the console after restart: `/survivors set foremanDailyCalls 40` (the server's tuning.properties still holds 400),
   and leave `panicChance` 0.07, `buddyLossChance` 0.01, `crewRhythm` 1, `trustRate` 1, `radioMinutes` 10,
   `radioDistance` 200 at their defaults.
5. Relaunch Prism (`build/tools/relaunch_prism.ps1`). Found-colony checklist as before: mark a supply chest, hire crew.
6. Watch the log for `Foreman[...] round N: using claude-sonnet-5-5|claude-opus-5-5` and `/foreman usage` for cached
   input. If the crew do something you don't want at dawn/dusk, `/survivors set crewRhythm 0` turns the routine off live.

## 4. What each order changed (one paragraph each; details in each branch's commit)

- **A+B quests and grace** (`build/quest_chapters.py`, `quest_engine.py`, `overrides/kubejs/.../horror_grace.js`): gate2
  depends on tunnels+dweller (track optional); gate3 any 2 of walls/infection/angels; gate4 any 2 of four dimensions;
  gate5 airship or Moon; engine supports `min_deps` and chapter `links`; "Before It's Too Late" linked on the Act 1
  page; gas mask reward on Survive the First Night, 4 cryo grenades on District One Is Lit; spore chapter early kit at
  the top; infection mobs (spore, sporeinquisition, infnexus) wait until day 5, other horrors day 3.
- **C foreman spend** (`colony/Foreman.java`, new `colony/WatchNotices.java`, `Guard.java`, `HaikuClient.java`):
  system prompt sent as cached static block + live block (tools first); Haiku prompt split the same way; colony watch
  posts fixed action-bar notices to online colony managers once per situation per hour and only spends a model turn on
  an unknown situation; `foremanDailyCalls` default 40; Opus only for why/stuck, jobs and failed-report follow-ups,
  Sonnet otherwise; `/foreman usage` shows Opus/Sonnet counts and cached vs uncached input.
- **D chat budget** (new `dialogue/Channel.java` + routing in Dialogue, Guide, Hearing, Crew, Foreman, Growth,
  SurvivorEntity, Initiative): CHAT for must-know (replies, order ended, hurt/distress, deaths, foreman answers, the
  chorus line), BAR (action bar, hidden by `/foreman subtitles off`) for everything else; home chatter while all players
  are >200 blocks from the town hall capped at one chat line per 10 minutes. Judgment call to review: "✦ joined the
  crew" moved to BAR.
- **E phrasebook** (new `colony/Phrasebook.java`, hooks in Foreman, Crew.groupHeard, Skills.names, bench `test phrase`):
  saved skills by name, then ~20 plain orders (wood/stone/sand/gravel/dirt/clay/coal gathers with counts and wood
  kinds, come here, follow, wait, stop, go home, guard here, light this up, plant trees, farm, sort chest, bring me X,
  dig, pick up, deposit, attack) run with no model and no daily-cap spend; questions and negations go to the model.
  Left out: the automatic "Saved as a skill" offer after a successful model plan.
- **F daily rhythm** (new `colony/Rhythm.java`, `ColonyBridge.waiting`, `Camp.darkSpots` public, hooks in
  SurvivorEntity/Crew/Foreman): phases from the clock; dawn/day gather what workers are waiting on (or top up logs/cobble
  to 256) in 10-minute shifts with eat breaks; late afternoon everyone home, first arrival does a torch pass from chest
  torches; dusk rotation picks the night watcher (GUARD at the chest), others stay within 8 blocks; routine tasks carry
  `project=AUTO`, never report, never call a model; orders drop them and pause the rhythm 60 s. Not done: saplings
  (GATHER excludes them), crops only when requested.
- **G senses and panic** (new `entity/Senses.java`, `entity/Panic.java`, hooks in SurvivorEntity, Tasks, Initiative,
  GameEvents): hurt -> back off toward player/home unless armed and healthy; player hurt within 16 -> approach, target
  the mob if armed; night falls far from home -> walk home; fear crossing 60 near a horror -> hide behind the nearest
  player. `panicChance` 0.07 on scare events: DROP_AND_RUN, HOLE (many safety checks), SCREAM, ROOF, HIDE_BEHIND;
  60 s or a player adjacent; orders queue during panic. Known gap: "follow me" still clears a panicking survivor's tasks.
- **H buddy rule** (new `entity/Buddy.java`, hooks in SurvivorEntity.hurt/die/NBT, Tasks.TaskGoal, Crew.stopAll):
  night task >24 blocks from home -> ask a nearby player, else pair with an idle crew mate (follows by navigation), else
  refuse; pairs cancel lethal mob hits and go slowed 60 s (transient speed modifier, removed in three places);
  `buddyLossChance` 0.01 rolled once per pair, one random member loses armor, never both; alone = no armor.
- **I trust** (new `entity/Trust.java`, hooks in SurvivorEntity, Job, Tasks, Dialogue): 0-100 (start 60), rises +5
  for protection/food/bed/light/orders ending at home, falls -2 (10-min cooldowns, floor 30) for alone at night, hurt
  with a passive player near, a day of neglect; work speed 0.7-1.15, +2 s reply delay under 45, grumbles under 40,
  tips and `trustsYou()` at 80+; crew leave only after 3 low days with two warnings; any interaction resets.
  Judgment call: finished orders count as interaction for crew.

## 6. Running a cloud session on this (what worked today)

- Attach `judsonj/horror-pack-dev` to the session (ask Claude to add the repo). Clone is shallow; fetch `main` before pushing.
- The git proxy allows two concurrent git operations on a repo: push branches one at a time.
- One `git worktree` per order under `/home/user/hpd-<order>`, agents never share a tree; merge into an integration
  worktree and resolve the (small, adjacent) conflicts in `Tuning.java`, `SurvivorEntity.java` fields/tick, `Foreman.heard`.
- `cd coremod && ./gradlew build` works once the Maven hosts above are allowed (first run ~3 min for the toolchain).
- `py resolve_mods.py` fetches the jars (Modrinth reachable) but **picks newer versions than `modlist.json` pins**:
  revert `modlist.json` and download the pinned files it names before `make_mrpack.py`.
- Test server recipe: download `neoforge-21.1.262-installer.jar` from maven.neoforged.net, `java -jar installer.jar
  --install-server <dir>`, copy `build/jars/*.jar build/extra_jars/*.jar build/server_only_jars/*.jar` minus
  `server_skip.txt` into `mods/`, copy `build/overrides/config` and `kubejs` plus `build/server_configs`, `eula=true`,
  `-Xmx8G`. Feed the console through a FIFO held open by a background `sleep`; never `pkill -f` a string that appears
  in your own command line. After `test setup` the bench now keeps the colony area entity-ticking, so crew move with no
  player online. The survivors' entity type is `survivors:survivor`; select them with `sort=nearest`, not by name.
  `/damage <survivor> 5 minecraft:mob_attack by <zombie>` is the quickest way to fire the hurt/panic path.
- `make_packwiz.py` deletes everything but `.git` and `README.md` in its output folder: point `build/packwiz` at a
  clone of the public repo on a branch, and restore `docs/` afterwards (`git checkout -- docs`).
